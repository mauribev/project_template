# `_examples/` — Format references, not this project's content

The `methodology_*.md` and `learning_*.md` files in this folder are **carried over from a previous project (BRCiS III)** purely as **examples of the expected depth and format** for deep methodology write-ups.

- They are **not** about this project. Do not treat their content as project context.
- Use them to see *how thorough* a `methodology_<topic>.md` should be (clean math first, then plain-language step-by-step; real references with links).
- When you write a real methodology doc for *this* project, create it one level up in `04_knowledge_base/` (e.g. `methodology_attrition.md`), not inside `_examples/`.
- Safe to delete this whole folder once the team is comfortable with the format.
