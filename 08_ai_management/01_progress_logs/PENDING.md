# PENDING — Open and Recently Done Items

Project-wide tracker for items that span sessions. **Open** items are still active; **Recently Done** items are pruned periodically — the session logs are the permanent history.

## Conventions

- Each item: `` `[YYYY-MM-DD]` `` (date added) + **Title.** + 1-line description + *Origin* reference to the originating session log.
- When an item is completed: move from `## Open` to `## Recently Done` with a trailing `` `→ done YYYY-MM-DD` `` tag.
- **Pruning:** Recently Done items older than ~30 days (or at milestone boundaries) can be deleted. The session log entries for those dates contain the full record of what was done.
- **Cancelled / wontfix:** items deliberately deprioritized go to `## Cancelled / Wontfix` with a one-line reason. Same pruning policy.
- New entries added to a session log's `⏭️ Next Steps` block must also be added here. PENDING.md is the consolidated cross-session view; session logs are the per-day chronicle.
- When an open item advances or closes a workstream, also reflect the new state in `WORKSTREAMS.md`.
