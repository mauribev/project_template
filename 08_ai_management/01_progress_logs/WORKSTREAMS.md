# WORKSTREAMS — Topic-Indexed Status Board

The **synthesis layer** of the tracking system: a "table of contents by theme" over the chronological logs. Where the session logs answer *"what did we do that day?"*, this file answers *"where do we stand on **survey design** / **analysis** / …?"* without making anyone re-read 20 dated logs.

It is an **index, not a diary**. Each workstream gets a short Current State and a dated Advances list, and then *points out* to the detailed records: the relevant session log, the `decision_log.md` entry, and the open `PENDING.md` items.

## How to maintain it

- **One section per workstream.** Add/rename/remove sections to fit the project. The list below is a starter set — delete what doesn't apply.
- **Update on state change, not on every session.** Touch a workstream only when its *state* meaningfully moves (a phase completes, a decision lands, a blocker appears/clears). Not every session touches every workstream.
- **Keep it short.** A few lines of Current State + a handful of dated Advances bullets. Synthesize; link out for detail.
- **Link, don't duplicate.** Reference `2026-01-15_session.md`, `decision_log.md → [Decision Title]`, `PENDING.md → [item]` rather than restating them.
- **Status values:** 🔴 Not started · 🟡 In progress · 🟢 Done / stable · ⏸️ Paused / blocked.
- Follow `@08_ai_management/03_system_templates/workstream_template.md` for each entry's shape.

**Legend:** 🔴 Not started 🟡 In progress 🟢 Done/stable ⏸️ Blocked
